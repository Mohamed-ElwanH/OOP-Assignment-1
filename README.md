This is a C++ image editing  program that lets user add different filters and effects to images by manipulating pixels.
The program allows users to:

Load a new image

Reads an image file and stores it in memory for editing.

Apply Filters and Effects, including:

Grayscale – Converts the image to shades of gray.

Black & White – Threshold-based filter producing a pure black-and-white version.

Invert Colors – Inverts every pixel’s RGB values.

Rotate Image – Rotates by 90°, 180°, or 270°.

Flip Image – Flips horizontally or vertically.

Crop Image – Cuts a selected rectangular portion.

Adjust Brightness – Increases or decreases brightness by a user factor.

Blur – Applies a smoothing effect using a two-pass box blur algorithm.

Frame – Adds either a solid border or a simple line-style frame.

Retro TV Effect – Simulates an old TV look by alternating pixel brightness.

Save the edited image under a custom file name.
